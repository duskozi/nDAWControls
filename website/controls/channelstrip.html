Controls / Mixer and layout

ChannelStrip

A complete mixer channel: name, pan, fader with a dB scale, stereo meter, mute, solo and arm.

<daw:ChannelStrip>
SkinGraphite

#Overview

ChannelStrip puts everything a mixer channel needs in one control. Volume is in dB (-70 = -∞ up to +6), Pan goes from -1 to 1, and IsMuted, IsSoloed and IsArmed bind two-way. The stereo meter is fed with PushLevels from any thread, like LevelMeter.

Use it for

  • mixer windows, a mixer panel docked under an arranger, a master section

#Quick start

XAML
<StackPanel Orientation="Horizontal">
    <daw:ChannelStrip TrackName="Kick" TrackColor="#FFFF6B5A" Volume="{Binding KickDb, Mode=TwoWay}"/>
    <daw:ChannelStrip TrackName="Bass" TrackColor="#FF6FA8FF" Volume="-6" Pan="-0.2"/>
    <daw:ChannelStrip TrackName="Master" ShowArmButton="False"
                      TrackColor="{DynamicResource {x:Static daw:DawSkinKeys.Accent}}"/>
</StackPanel>
C#
strip.PushLevels(peakLeft, rmsLeft, peakRight, rmsRight);   // any thread, linear values

#Examples

#A mixer from a collection

Bind an ItemsControl to your tracks. See the mixer recipe for the full view-model and meter feed.

XAML
<ItemsControl ItemsSource="{Binding Tracks}">
    <ItemsControl.ItemsPanel>
        <ItemsPanelTemplate><StackPanel Orientation="Horizontal"/></ItemsPanelTemplate>
    </ItemsControl.ItemsPanel>
    <ItemsControl.ItemTemplate>
        <DataTemplate>
            <daw:ChannelStrip TrackName="{Binding Name}" TrackColor="{Binding Color}"
                              Volume="{Binding Volume, Mode=TwoWay}" Pan="{Binding Pan, Mode=TwoWay}"
                              IsMuted="{Binding IsMuted, Mode=TwoWay}" IsSoloed="{Binding IsSoloed, Mode=TwoWay}"
                              IsArmed="{Binding IsArmed, Mode=TwoWay}" Margin="0,0,4,0"/>
        </DataTemplate>
    </ItemsControl.ItemTemplate>
</ItemsControl>

#Busses and the master

Hide the arm button where recording makes no sense:

XAML
<daw:ChannelStrip TrackName="Reverb" ShowArmButton="False" TrackColor="#FFB18CFF"/>

#Mouse and keyboard

InputWhat it does
FaderDrag, wheel or arrow keys; double-click for 0 dB
Pan knobDrag; double-click for centre
M / S / RMute, solo, arm
Clip lightsClick to clear

#API reference

#Properties

PropertyTypeDefaultDescription
TrackNamestring"Track"Name shown at the top of the strip.
TrackColorBrushnullTrack colour, shown as the strip's top bar and the pan arc.
Volumedouble0Fader level in dB (-70 = -∞ … +6).
Pandouble0-1 (left) … +1 (right).
IsMutedbool—Whether the track is muted.
IsSoloedbool—Whether the track is soloed.
IsArmedbool—Whether the track is armed for recording.
ShowArmButtonbooltrueHide Arm on busses / master.
PeakLeftdouble—Left peak level as linear gain (1 = 0 dBFS).
PeakRightdouble—Right peak level as linear gain (1 = 0 dBFS).
RmsLeftdouble—Left RMS level as linear gain (1 = 0 dBFS).
RmsRightdouble—Right RMS level as linear gain (1 = 0 dBFS).

#Methods

MethodDescription
PushLevels(float peakLeft, float rmsLeft, float peakRight, float rmsRight)Thread-safe: forwards audio-thread levels to both meters (see PushLevels).
