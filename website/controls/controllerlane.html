Controls / Note editing

ControllerLane

Velocity, controller and pitch-bend editing under a piano roll, following its scroll, zoom and playhead.

<daw:ControllerLane>
SkinGraphite

#Overview

ControllerLane sits under a PianoRoll. Point Roll at the roll and the lane follows its scroll position, zoom, snap and playhead. In Velocity mode it edits the velocities of the roll's notes; in Controller and PitchBend mode it edits a list of ControllerPoints.

#Quick start

XAML
<Grid>
    <Grid.RowDefinitions>
        <RowDefinition Height="*"/>
        <RowDefinition Height="100"/>
    </Grid.RowDefinitions>
    <ScrollViewer CanContentScroll="True" HorizontalScrollBarVisibility="Auto">
        <daw:PianoRoll x:Name="roll"/>
    </ScrollViewer>
    <daw:ControllerLane Grid.Row="1" Roll="{Binding ElementName=roll}" Mode="Velocity"/>
</Grid>

#Examples

#A controller lane

C#
lane.Mode = LaneMode.Controller;
lane.ControllerNumber = 1;                        // modulation
lane.Points = new ObservableCollection<ControllerPoint>
{
    new(0, 0), new(4, 127), new(8, 64),          // position in beats, value 0..127
};
lane.LaneEdited += (s, e) => SaveLane();

#Pitch bend

In PitchBend mode the values go from -8192 to 8191:

C#
lane.Mode = LaneMode.PitchBend;
lane.Points = new ObservableCollection<ControllerPoint> { new(0, 0), new(2, 4096), new(3, 0) };

#Switching lanes with a picker

The MIDI player sample offers a list of lanes:

C#
(string Label, int Controller, LaneMode Mode)[] lanes =
{
    ("Velocity", 0, LaneMode.Velocity), ("CC 1 · Modulation", 1, LaneMode.Controller),
    ("CC 7 · Volume", 7, LaneMode.Controller), ("CC 64 · Sustain", 64, LaneMode.Controller),
    ("Pitch bend", -1, LaneMode.PitchBend),
};

#Mouse and keyboard

InputWhat it does
DragDraws values
Shift + dragDraws a straight line
Right-dragErases events

#Tips

PaintStep sets the spacing of points created while drawing (1/32 note by default).

#API reference

#Properties

PropertyTypeDefaultDescription
RollPianoRollnullThe piano roll this lane is aligned with (scroll, zoom, snap, notes, playhead).
ModeLaneModeVelocityWhat the lane shows and edits: velocities, a controller or pitch bend.
PointsIList<ControllerPoint>nullController / pitch-bend events for Controller and PitchBend. Kept sorted by position.
ControllerNumberint1CC number shown in the header (1 = modulation, 7 = volume, 11 = expression, 64 = sustain…).
PaintStepdouble0.125Spacing of points created while drawing, in beats (default 1/32 note).
Colour properties (5)

Each one is set by the skin. Set it on one control to override the skin for that control only.

PropertyDescription
ValueBrushBrush for the value bars and points.
FillBrushBrush for the area under the values or the curve.
GridBrushBrush for the grid lines.
HeaderBrushBrush for the header column.
PlayheadBrushBrush for the playhead line.
