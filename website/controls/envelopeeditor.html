EnvelopeEditor

A graphical ADSR envelope: drag the handles to set attack, decay, sustain and release.

<daw:EnvelopeEditor>
SkinGraphite

#Overview

EnvelopeEditor shows a classic ADSR shape with four handles. Attack, Decay and Release are in seconds, and Sustain is a level from 0 to 1. All four are dependency properties, so bind them two-way to your synth parameters.

Each of the three time segments gets its own lane of up to MaxSegmentTime seconds. TimeScale maps time to width with a square-law curve by default, so short attacks of a few milliseconds are still easy to grab.

Use it for

  • amplitude, filter and modulation envelopes of a synth or sampler

#Quick start

XAML
<daw:EnvelopeEditor Width="320" Height="150" MaxSegmentTime="5"
                    Attack="{Binding Attack, Mode=TwoWay}"   Decay="{Binding Decay, Mode=TwoWay}"
                    Sustain="{Binding Sustain, Mode=TwoWay}" Release="{Binding Release, Mode=TwoWay}"/>

#Examples

#Straight or curved segments

Curvature only changes the drawing: 0 draws straight lines, 1 strongly exponential, analog-style curves.

XAML
<daw:EnvelopeEditor Width="320" Height="150" Curvature="0" Attack="0.3" Decay="0.6" Sustain="0.5" Release="1.2"/>

#Undo per drag

C#
env.DragStarted   += (s, e) => undo.BeginGroup("Envelope");
env.DragCompleted += (s, e) => undo.EndGroup();

#Mouse and keyboard

InputWhat it does
Drag a handleChanges the time and/or level of that point
Shift + dragFine changes
Double-click a handleResets that segment to its default

#API reference

#Properties

PropertyTypeDefaultDescription
Attackdouble—Attack time in seconds.
Decaydouble—Decay time in seconds.
Releasedouble—Release time in seconds.
Sustaindouble0.7Sustain level, 0 to 1.
MaxSegmentTimedouble4Longest attack/decay/release (seconds) – the full width of one segment lane.
Curvaturedouble0.60 = straight lines, 1 = strongly exponential (analog-style) segments. Display only.
TimeScaleValueTapersquare-lawHow time maps to segment width. Default is a square-law curve so short attacks (1–50 ms) get usable resolution while multi-second releases still fit.
Colour properties (4)

Each one is set by the skin. Set it on one control to override the skin for that control only.

PropertyDescription
StrokeBrushBrush for the curve.
FillBrushBrush for the area under the values or the curve.
HandleBrushBrush for the drag handles.
GridBrushBrush for the grid lines.
