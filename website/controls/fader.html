Fader

A slider with a moving cap, vertical or horizontal, with a decibel curve for mixer channels.

<daw:Fader>
SkinGraphite

#Overview

Fader is the long-throw slider of a mixing desk. Like Knob it is a value control, so everything about Minimum, Maximum, Taper, DefaultValue and the value text works the same way.

With Taper="Decibel" the travel follows the usual mixer curve: lots of room around 0 dB and the bottom compressed towards -∞.

Use it for

  • channel and master volume in a mixer
  • sends, glide, crossfades and other long-throw values (horizontal)

#Quick start

XAML
<daw:Fader Height="220" Taper="Decibel" Minimum="-60" Maximum="6" DefaultValue="0" MinimumText="-∞"
           Value="{Binding VolumeDb, Mode=TwoWay}"
           ValueFormatter="{x:Static daw:ValueFormatters.Decibel}"/>

#Examples

#Horizontal fader

XAML
<daw:Fader Orientation="Horizontal" Width="220" Height="24" Label="Glide" Value="0.25"
           ValueFormatter="{x:Static daw:ValueFormatters.Percent}"/>

#Fader with a dB scale and a meter

Put a ValueScale and a LevelMeter next to the fader. The fader cap is 40 pixels high, so padding the scale and the meter by 20 at the top and bottom lines the ticks up with the middle of the cap. Use the same Taper, Minimum and Maximum on the scale as on the fader.

XAML
<StackPanel Orientation="Horizontal">
    <daw:ValueScale Placement="End" Padding="0,20,0,20" Minimum="-60" Maximum="0" Taper="Decibel"
                    MinimumText="-∞" Ticks="0 -3 -6 -12 -20 -30 -60"/>
    <daw:Fader Width="30" Height="240" Taper="Decibel" Minimum="-60" Maximum="0" ShowValueText="False"/>
    <daw:LevelMeter x:Name="meter" Width="8" Margin="4,20,0,20"/>
</StackPanel>

#Jump to a click

By default a click on the track does nothing and only the cap can be dragged, as on hardware. IsMoveToPointEnabled="True" moves the cap to the click.

XAML
<daw:Fader Height="160" IsMoveToPointEnabled="True"/>

#Linking dB and gain

Faders work in dB. Convert to a linear gain for your audio engine:

C#
fader.ValueChanged += (s, e) =>
{
    double db = e.NewValue;
    float gain = db <= fader.Minimum ? 0f : (float)Math.Pow(10, db / 20);
    engine.SetChannelGain(channel, gain);
};

#Mouse and keyboard

Drag the capMoves the fader (Shift for fine)
Mouse wheelSmall steps
Double-clickBack to DefaultValue
Arrow keys, Page Up/Down, Home/EndSteps, large steps, ends

#Tips

  • ShowValueText="False" hides the readout under the fader when your layout shows the value elsewhere.
  • For a full mixer channel with pan, mute, solo and meters in one control, use ChannelStrip.

#API reference

#Properties

Fader also has everything from WPF's RangeBase (Minimum, Maximum, Value, ValueChanged, SmallChange, LargeChange) and the shared value-control properties (DefaultValue, Taper, Step, Label, ValueFormatter, MinimumText …).

PropertyTypeDefaultDescription
OrientationOrientationVerticalVertical (default) or horizontal.
ShowValueTextbooltrueShow the value readout under the fader (turn off when the host shows it elsewhere).
IsMoveToPointEnabledboolfalseClicking the track (not the cap) jumps the cap to the mouse.
