Controls / Parameters

Knob

A rotary control with a value ring, a label and a value readout. The workhorse of every synth and effect panel.

<daw:Knob>
SkinGraphite

#Overview

Knob is a value control: it derives from WPF's RangeBase, so Minimum, Maximum, Value and ValueChanged work as you know them. It draws a ring that fills from the minimum (or from the middle for bipolar knobs), the parameter name under it, and the value as text.

The value text comes from ValueFormatter or ValueStringFormat, and the drag curve from Taper, so a frequency knob feels right across its whole range.

Use it for

  • synth and effect parameters: cutoff, resonance, drive, attack, mix
  • pan and send knobs in a mixer (IsBipolar="True" for pan)
  • any value where a slider would take too much room

#Quick start

Bind Value two-way to your view-model, like any WPF range control:

XAML
<daw:Knob Label="Cutoff" Minimum="20" Maximum="20000" Taper="Log" DefaultValue="1200"
          Value="{Binding Cutoff, Mode=TwoWay}"
          ValueFormatter="{x:Static daw:ValueFormatters.Frequency}"/>

#Examples

#Units in the value text

Use a format string for simple units, or one of the ready-made ValueFormatters (Decibel, Pan, Percent, Frequency, Time, Tempo, Integer).

XAML
<daw:Knob Label="Gain"   Minimum="0" Maximum="24" Value="6" ValueStringFormat="{}{0:0.0} dB"/>
<daw:Knob Label="Mix"    Value="0.8" ValueFormatter="{x:Static daw:ValueFormatters.Percent}"/>
<daw:Knob Label="Attack" Minimum="0.001" Maximum="5" Taper="Log" Value="0.02"
          ValueFormatter="{x:Static daw:ValueFormatters.Time}"/>

#Bipolar knob for pan

With IsBipolar="True" the ring starts at DefaultValue and grows to either side.

XAML
<daw:Knob Label="Pan" IsBipolar="True" Minimum="-1" Maximum="1" DefaultValue="0"
          Value="{Binding Pan, Mode=TwoWay}" ValueFormatter="{x:Static daw:ValueFormatters.Pan}"/>

#Stepped knob

Step snaps every user change to a multiple. Here the knob picks a whole number of semitones:

XAML
<daw:Knob Label="Transpose" Minimum="-24" Maximum="24" Step="1" DefaultValue="0"
          ValueStringFormat="{}{0:+0;-0;0} st"/>

#Your own formatter

ValueFormatter is a Func<double, string>, so any text is possible:

C#
waveKnob.Minimum = 0;
waveKnob.Maximum = 3;
waveKnob.Step = 1;
waveKnob.ValueFormatter = v => ((int)v) switch { 0 => "Sine", 1 => "Triangle", 2 => "Saw", _ => "Square" };

#Colour, size and sweep

ArcBrush sets the ring colour of one knob (the skin accent otherwise). The knob scales with its size. MinAngle and MaxAngle change the sweep, measured from 12 o'clock.

XAML
<daw:Knob Label="Mix" ArcBrush="#FFB18CFF" Value="0.8"/>
<daw:Knob Label="Small" Width="36" Height="48" Value="0.5"/>
<daw:Knob Label="Wide" MinAngle="-150" MaxAngle="150" Value="0.3"/>

#Reacting to changes

ValueChanged fires for every change. For automation or undo, DragStarted and DragCompleted tell you when a gesture starts and ends, so one drag becomes one undo step.

C#
cutoff.ValueChanged   += (s, e) => synth.SetCutoff(e.NewValue);
cutoff.DragStarted    += (s, e) => undo.BeginGroup("Cutoff");
cutoff.DragCompleted  += (s, e) => undo.EndGroup();

#Mouse and keyboard

InputWhat it does
Drag up or downChanges the value. The full range is DragSensitivity pixels (200 by default).
Shift + dragFine steps (FineFactor, 0.1 by default)
Mouse wheelSmall steps, Shift for finer steps
Double-click, Ctrl+click or DeleteBack to DefaultValue
Arrow keysSmall steps (Shift for finer)
Page Up / Page DownLarge steps
Home / EndMinimum / maximum

#Tips

  • Set DefaultValue on every knob. Double-click to reset is what users of audio software expect.
  • Taper="Log" needs a positive Minimum (20 Hz, not 0).
  • The knob takes keyboard focus, so it works in tab order and with screen readers like other RangeBase controls.

#API reference

#Properties

Knob also has everything from WPF's RangeBase (Minimum, Maximum, Value, ValueChanged, SmallChange, LargeChange) and the shared value-control properties (DefaultValue, Taper, Step, Label, ValueFormatter, MinimumText …).

PropertyTypeDefaultDescription
MinAngledouble-135Angle at minimum, degrees from 12 o'clock (default -135).
MaxAngledouble135Angle at maximum, degrees from 12 o'clock (default 135).
IsBipolarboolfalseWhen true the value ring starts at the default value instead of the minimum.
Colour properties (1)

Each one is set by the skin. Set it on one control to override the skin for that control only.

PropertyDescription
ArcBrushColour of the value ring (defaults to the skin accent; set per knob to colour-code parameters).
