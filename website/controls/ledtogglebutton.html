Controls / Buttons and transport

LedToggleButton

A latching button that lights up when on: mute, solo, record arm, monitor and your own toggles.

<daw:LedToggleButton>
SkinGraphite

#Overview

LedToggleButton is a WPF ToggleButton, so IsChecked, Command and Content work as usual. Role picks the lit colour from the skin; LitBrush sets your own.

Use it for

  • M / S / R buttons, view toggles, tool buttons, any on/off option in a DAW-style toolbar

#Quick start

XAML
<daw:LedToggleButton Role="Mute"      Content="M"   IsChecked="{Binding IsMuted}"/>
<daw:LedToggleButton Role="Solo"      Content="S"   IsChecked="{Binding IsSolo}"/>
<daw:LedToggleButton Role="RecordArm" Content="R"   IsChecked="{Binding IsArmed}"/>
<daw:LedToggleButton Role="Monitor"   Content="MON"/>

#Examples

#Own colour

XAML
<daw:LedToggleButton Content="LEGATO" LitBrush="#FF35D08A" Padding="10,0" Height="24"/>

#As a view switch

Two buttons that act like tabs (the gallery header works this way):

XAML
<StackPanel Orientation="Horizontal">
    <daw:LedToggleButton x:Name="ShowMixer" Content="MIXER" IsChecked="True" Click="OnViewClick"/>
    <daw:LedToggleButton x:Name="ShowEditor" Content="EDITOR" Margin="4,0,0,0" Click="OnViewClick"/>
</StackPanel>
C#
void OnViewClick(object sender, RoutedEventArgs e)
{
    bool mixer = sender == ShowMixer;
    ShowMixer.IsChecked = mixer;
    ShowEditor.IsChecked = !mixer;
}

#Tips

Roles: Generic (accent colour), Mute, Solo, RecordArm and Monitor. The colours are skin keys (LedMute, LedSolo, LedArm, LedMonitor), so you can change them per skin.
