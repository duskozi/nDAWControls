Controls / Metering

LevelMeter

A peak and RMS meter with peak hold and a clip light, fed lock-free from your audio thread.

<daw:LevelMeter>
SkinGraphite

#Overview

LevelMeter shows a translucent peak bar with a solid RMS bar inside, a peak-hold line and a clip light. The colours change at WarningDb and DangerDb.

It is built for real-time audio: PushLevels can be called from the audio thread, takes no lock and doesn't touch the dispatcher. The meter collects the newest values and draws once per frame, with smooth ballistics (ReleaseRate, PeakHoldTime).

Use it for

  • channel, bus and master meters, input meters, gain-reduction style displays (horizontal)

#Quick start

Place the meter, then push levels from your audio callback:

XAML
<daw:LevelMeter x:Name="meter" Width="10" Height="200"/>
C#
void OnAudioBlock(float[] samples)          // audio thread
{
    float peak = 0, sum = 0;
    foreach (float s in samples) { peak = Math.Max(peak, Math.Abs(s)); sum += s * s; }
    meter.PushLevels(peak, MathF.Sqrt(sum / samples.Length));   // linear, 1 = 0 dBFS
}

#Examples

#Horizontal meter with its own range

XAML
<daw:LevelMeter Orientation="Horizontal" Width="240" Height="10" MinDb="-48" MaxDb="0" ShowRms="True"/>

#LED ladder

SegmentSize splits the bar into LED segments with a 1-pixel gap.

XAML
<daw:LevelMeter Width="12" Height="200" SegmentSize="4" WarningDb="-18" DangerDb="-6"/>

#Binding instead of pushing

When the levels already live in your view-model, bind Peak and Rms (linear values). Pushing is better for audio-thread data.

XAML
<daw:LevelMeter Width="10" Height="180" Peak="{Binding PeakLevel}" Rms="{Binding RmsLevel}"/>

#Clip light

IsClipped latches when a peak reaches 0 dBFS. The user clears it with a click on the light; you can clear it with IsClipped = false, or clear everything with Reset() when playback stops.

C#
transport.StopCommand = new RelayCommand(() =>
{
    engine.Stop();
    foreach (var m in meters) m.Reset();
});

#Tips

  • Push linear values (0 to 1, where 1 is 0 dBFS), not dB. Values above 1 show as clipping.
  • Push as often as you like. Only the newest values are drawn, once per frame.
  • A collapsed meter (in a hidden panel) draws nothing, so hidden meters cost no CPU.

#Properties

PropertyTypeDefaultDescription
Peakdouble0Current peak as linear gain (1.0 = 0 dBFS).
Rmsdouble0Current RMS as linear gain.
OrientationOrientationVerticalVertical (default) or horizontal.

MaxDbdouble6Level in dB at the top of the meter.

Colour properties (6)

Each one is set by the skin. Set it on one control to override the skin for that control only.

PropertyDescription
SafeBrushBrush for the part of the meter below WarningDb.
WarningBrushBrush for the part of the meter between WarningDb and DangerDb.
DangerBrushBrush for the part of the meter above DangerDb.
PeakHoldBrushBrush for the held-peak line.
ClipOnBrushBrush for the clip LED while lit.
ClipOffBrushBrush for the clip LED while off.

#Methods

MethodDescription
PushLevels(float peak, float rms)Thread-safe, lock-free. Call from the audio thread with the block's peak and RMS (linear gain). Multiple pushes per frame are merged by taking the maximum.
Reset()Clears ballistics, peak hold and the clip LED.
