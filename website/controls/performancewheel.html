Controls / Piano

PerformanceWheel

Hardware-style pitch-bend and modulation wheels.

<daw:PerformanceWheel>
SkinGraphite

#Overview

PerformanceWheel is drawn as a ribbed cylinder in a slot. In PitchBend mode the value goes from -8192 to 8191 and the wheel springs back to the centre when released; in Modulation mode it goes from 0 to 127 and stays where it is left.

#Quick start

XAML
<StackPanel Orientation="Horizontal">
    <daw:PerformanceWheel x:Name="pitch" Mode="PitchBend" Height="110"/>
    <daw:PerformanceWheel x:Name="mod" Mode="Modulation" Height="110" Margin="6,0,0,0"/>
</StackPanel>
C#
pitch.ValueChanged += (s, e) => midiOut.PitchBend(0, e.NewValue);        // -8192..8191
mod.ValueChanged   += (s, e) => midiOut.ControlChange(0, 1, e.NewValue);  // CC 1, 0..127

#Examples

#Showing incoming MIDI

Setting Value from code moves the wheel and raises ValueChanged too, so guard against sending it back:

C#
bool fromInput;
void OnMidiPitchBend(int value) => Dispatcher.BeginInvoke(() =>
{
    fromInput = true; pitch.Value = value; fromInput = false;
});
pitch.ValueChanged += (s, e) => { if (!fromInput) midiOut.PitchBend(0, e.NewValue); };

#A wheel that stays

XAML
<daw:PerformanceWheel Mode="PitchBend" SpringReturn="False" Label="BEND"/>

#Mouse and keyboard

Drag up or downMoves the wheel (Shift for fine)
Mouse wheel / Up and Down keysSteps
Release (pitch bend)Springs back to the centre
Double-click, Home or DeleteBack to the rest position

#API reference

#Properties

PropertyTypeDefaultDescription
ModeWheelModePitchBendPitch bend (springs back to the centre) or modulation (stays where it is left).
Valueint0Pitch bend: -8192..8191. Modulation: 0..127.
SpringReturnbooltruePitch-bend mode only: return to centre on release (like a real spring-loaded wheel).
DragSensitivitydouble140Pixels of vertical mouse travel for the full range.
LabelstringnullCaption under the wheel ("PB", "MOD"). Null = derived from Mode; empty = none.
Colour properties (4)

Each one is set by the skin. Set it on one control to override the skin for that control only.

PropertyDescription
SlotBrushBrush for the slot around the wheel.
WheelBrushBrush for the wheel body.
RibBrushBrush for the ribs of the wheel.
MarkerBrushBrush for the centre marker.

#Events

EventHandlerDescription
ValueChangedRoutedPropertyChangedEventHandler<int>Raised for every value change (drag, spring-back, binding). Send the MIDI message from here.
DragStartedRoutedEventHandlerRaised when the user grabs the wheel.
DragCompletedRoutedEventHandlerRaised when the user lets go of the wheel (a pitch wheel then springs back).
