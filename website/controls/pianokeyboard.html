Controls / Piano

PianoKeyboard

A playable piano keyboard in three styles, with velocity, highlights, finger numbers and computer-keyboard play.

<daw:PianoKeyboard>
SkinGraphite

#Overview

PianoKeyboard shows any range of MIDI notes (LowestNote to HighestNote, widened to white keys). Click or drag to play: lower on a key plays harder. With keyboard focus the computer keyboard plays too. NoteOn and NoteOff tell you what the user plays, and SetHighlighted lights keys from playback or MIDI input.

KeyStyle is ThreeD (the default), Flat or Grand. The Grand style draws ivory keys and red felt, and can show the hand and finger on lit keys.

Use it for

  • playing and auditioning notes, showing what a song or MIDI input plays, piano teaching apps with fingering

#Quick start

XAML
<daw:PianoKeyboard x:Name="keys" Height="100" LowestNote="36" HighestNote="96"/>
C#
keys.NoteOn  += (s, e) => midiOut.NoteOn(0, e.Note, e.Velocity);
keys.NoteOff += (s, e) => midiOut.NoteOff(0, e.Note);

#Examples

#Lighting keys from playback

C#
keys.SetHighlighted(60, velocity: 100);            // brightness follows the velocity
keys.SetHighlighted(64, 80, Brushes.Orange);       // own colour, e.g. the track colour
keys.SetHighlighted(60, false);                    // off again
keys.ClearHighlights();                            // everything off

#Grand style with fingering

SetState replaces all highlights in one redraw, with colour, intensity, hand (1 = left, 2 = right) and finger:

XAML
<daw:PianoKeyboard x:Name="grand" Height="110" LowestNote="21" HighestNote="108" KeyStyle="Grand" LabelMode="Fingers"/>
C#
grand.SetState(new[]
{
    new KeyHighlight(60, Colors.DodgerBlue, 1.0, Hand: 2, Finger: 1),   // right hand, thumb
    new KeyHighlight(64, Colors.DodgerBlue, 0.9, Hand: 2, Finger: 3),
    new KeyHighlight(48, Colors.Orange,     0.8, Hand: 1, Finger: 5),   // left hand, little finger
});

#Fixed velocity and labels

XAML
<daw:PianoKeyboard Height="80" FixedVelocity="100" ShowOctaveLabels="True" MiddleCOctave="3"
                   VelocitySensitiveLighting="False"/>

#Changing the range from code

C#
keys.SetRange(48, 84);     // C3..C6 (middle C = C4)
keys.ReleaseAll();         // releases held notes, e.g. when the window loses focus

#Mouse and keyboard

InputWhat it does
Click / dragPlays notes; lower on the key = higher velocity (unless FixedVelocity is set)
A W S E D F T G Y H U J KPlays an octave from C with the computer keyboard (needs focus)
Z / XOctave down / up for the computer keyboard

#Tips

  • The keyboard asks for 16 pixels per white key when it isn't stretched. Give it a Height; the theme default is 90.
  • Turn the computer keyboard off with IsComputerKeyboardEnabled="False" when your app uses those keys for shortcuts.

#API reference

#Properties

PropertyTypeDefaultDescription
LowestNoteint36Lowest MIDI note shown (widened to a white key).
HighestNoteint96Highest MIDI note shown (widened to a white key).
BlackKeyHeightRatiodouble0.62Height of the black keys as a fraction of the white keys.
ShowOctaveLabelsbooltrueWhether C keys are labelled with their octave (C3, C4 …).
MiddleCOctaveint4Octave number of MIDI note 60 in labels: 4 (Roland/scientific) or 3 (Yamaha/Cubase).
IsComputerKeyboardEnabledbooltrueWhether the computer keyboard plays notes while the control has focus (A W S E D … rows).
ComputerKeyboardOctaveint4Octave (in MIDI octaves, C4 = 60) the "A" key plays.
FixedVelocityint0When > 0 every note uses this velocity instead of the click position.
KeyStylePianoKeyStyleThreeDFlat keys, or sculpted keys with front lips, bevelled black keys, shadows and press depth.
VelocitySensitiveLightingbooltruePressed / highlighted keys glow brighter the harder the note was hit.
LabelModeKeyLabelModeFingersWhat lit keys show in the Grand style: finger numbers, note names or nothing.
Colour properties (4)

Each one is set by the skin. Set it on one control to override the skin for that control only.

PropertyDescription
WhiteKeyBrushBrush for the white keys.
BlackKeyBrushBrush for the black keys.
PressedKeyBrushBrush for the pressed keys.
HighlightKeyBrushBrush for the keys lit from playback.

#Events

EventHandlerDescription
NoteOnNoteEventHandlerRaised when a key is played with the mouse or computer keyboard.
NoteOffNoteEventHandlerRaised when a key played with the mouse or computer keyboard is released.

#Methods

MethodDescription
SetHighlighted(int note, bool on)Lights or clears a key (e.g. from incoming MIDI) at velocity 100. UI thread only. Does not raise events.
SetHighlighted(int note, int velocity)Lights a key with a brightness that follows velocity (1..127); 0 clears it. Feed it note-on velocities from MIDI input or playback. UI thread only. Does not raise events.
SetHighlighted(int note, int velocity, Brush? brush)Lights a key in a specific colour (e.g. the colour of the track playing it); null = HighlightKeyBrush. Velocity 0 clears the key. UI thread only. Does not raise events.
GetHighlightVelocity(int note)Highlight velocity of a key (0 = not lit).
ClearHighlights()Turns off every key lit with SetHighlighted().
SetState(IEnumerable<KeyHighlight> keys)Replaces every highlight with keys in one redraw: colour, brightness, and the hand and finger shown in the Grand style. When a note is listed twice the brighter one wins. UI thread only.
SetRange(int low, int high)Shows notes low to high (widened to white keys).
ReleaseAll()Releases every note currently held by mouse or computer keyboard (raises NoteOff for each).
HitTestNote(Point p)Returns the MIDI note at a point, or -1.
