Controls / Piano

PianoPedals

Soft, sostenuto and sustain pedals that show half-pedalling and can be pressed with the mouse.

<daw:PianoPedals>
SkinGraphite

#Overview

PianoPedals is a compact indicator (about 50 × 18 pixels by default) with up to three foot plates that fill from the bottom with their depth, so half-pedalling is visible. Values go from 0 (up) to 127 (down) and map to CC 67 (soft), 66 (sostenuto) and 64 (sustain).

#Quick start

XAML
<daw:PianoPedals x:Name="pedals" ShowSoft="True" ShowSostenuto="True"/>
C#
pedals.PedalChanged += (s, e) =>
{
    if (e.IsUserChange) midiOut.ControlChange(0, e.Controller, e.Value);   // only clicks, not playback
};

// Show pedals from a song or MIDI input: returns true for CC 64, 66 and 67.
pedals.ApplyControlChange(controller, value);

#Examples

#Display only, sustain only

XAML
<daw:PianoPedals IsInteractive="False" ShowSoft="False" ShowSostenuto="False" Width="24"
                 SustainValue="{Binding Sustain}"/>

#Setting a pedal from code

C#
pedals.SetPedal(PianoPedal.Sustain, 127);     // IsUserChange is false
int depth = pedals.GetPedal(PianoPedal.Soft);

#Mouse and keyboard

InputWhat it does
Hold the mouse on a pedalPresses it fully (127) until released
Mouse wheel on a pedalHalf-pedalling: changes the depth in steps of 8 (Shift: 1); the depth stays

#API reference

#Properties

PropertyTypeDefaultDescription
SoftValueint—Soft pedal depth 0..127 (CC 67).
SostenutoValueint—Sostenuto depth 0..127 (CC 66).
SustainValueint—Sustain depth 0..127 (CC 64). Feed incoming CC 64 straight into this.
ShowSoftbooltrueWhether the soft (una corda) pedal is shown.
ShowSostenutobooltrueMany digital pianos have no sostenuto; hide it to save space.
IsInteractivebooltrueFalse = display only (ignores the mouse).
Colour properties (2)

Each one is set by the skin. Set it on one control to override the skin for that control only.

PropertyDescription
PedalBrushPedal plate at rest.
LitBrushDepth fill / pressed colour.

#Events

EventHandlerDescription
PedalChangedPedalEventHandlerRaised whenever a pedal value changes (user or binding). Send the CC from here when IsUserChange is true.

#Methods

MethodDescription
ControllerOf(PianoPedal pedal)MIDI controller number of a pedal: 64, 66 or 67.
GetPedal(PianoPedal pedal)The value of a pedal, 0 (up) to 127 (down).
SetPedal(PianoPedal pedal, int value)Sets a pedal, 0 (up) to 127 (down), as a value from code: IsUserChange is false.
ApplyControlChange(int controller, int value)Applies an incoming MIDI controller message; returns false if it isn't a pedal CC.
