Controls / Note editing

PianoRoll

A fast note editor with a keyboard gutter, bar ruler, snapping, selection, zoom and a playhead.

<daw:PianoRoll>
SkinGraphite

#Overview

PianoRoll edits a list of MidiNotes. Only the visible part is drawn, so long songs with all 128 notes stay fast. Positions and lengths are in beats (quarter notes), and so is Snap (0.25 = sixteenth notes, 0 = off).

Give it an ObservableCollection<MidiNote>: every edit the user makes goes straight into that collection, and changes you make in code show at once. Put the roll in a ScrollViewer with CanContentScroll="True"; it scrolls itself.

Use it for

  • MIDI editors, sequencers, players that show the notes, music teaching and analysis tools

#Quick start

XAML
<ScrollViewer CanContentScroll="True" HorizontalScrollBarVisibility="Auto" VerticalScrollBarVisibility="Auto">
    <daw:PianoRoll x:Name="roll" LengthInBeats="64" BeatsPerBar="4" Snap="0.25" FollowPlayhead="True"/>
</ScrollViewer>
C#
var notes = new ObservableCollection<MidiNote>
{
    new(60, start: 0, length: 1, velocity: 100),     // C4
    new(64, 1, 1),                                   // E4
    new(67, 2, 2),                                   // G4
};
roll.Notes = notes;      // edits go straight into the collection

#Examples

#Hearing notes while editing

AuditionNoteOn fires when the user touches a note or clicks a key in the gutter:

C#
roll.AuditionNoteOn  += (s, e) => midiOut.NoteOn(0, e.Note, e.Velocity);
roll.AuditionNoteOff += (s, e) => midiOut.NoteOff(0, e.Note);

#Undo

NotesEdited fires once per finished gesture (mouse-up, key press), which is the right moment for an undo snapshot:

C#
var history = new Stack<List<MidiNote>>();
roll.NotesEdited += (s, e) => history.Push(notes.Select(n => n.Clone()).ToList());

#Playhead and follow

C#
CompositionTarget.Rendering += (s, e) => roll.PlayheadPosition = engine.PositionInBeats;
roll.PlayheadMoved += (s, e) => engine.Seek(roll.PlayheadPosition);   // the user clicked the ruler

#Colours per track

MidiNote.Brush colours one note. Use it to show several tracks in one roll:

C#
foreach (var n in bassNotes) { n.Brush = Brushes.CornflowerBlue; notes.Add(n); }

#Read-only roll for a player

XAML
<daw:PianoRoll Notes="{Binding Notes}" IsReadOnly="True" PixelsPerBeat="40" KeyHeight="8"
               PlayheadPosition="{Binding Position}" FollowPlayhead="True"/>

#Coordinates

For overlays and custom tools, the roll converts between beats/pitches and pixels:

C#
double x = roll.BeatToX(16);            // where bar 5 starts (4/4)
int pitch = roll.YToPitch(mouse.Y);
roll.ScrollIntoView(beat: 32, pitch: 60);

#Tips

  • PixelsPerBeat and KeyHeight are the zoom. Bind them to sliders, or let users zoom with Ctrl/Alt + wheel.
  • Without a width limit (an Auto column, a plain StackPanel) the roll asks for a limited size. Put it in a sized cell or a star-sized grid row.

#Events

EventHandlerDescription
AuditionNoteOnNoteEventHandlerThe user is touching a note or key – play it so they can hear the pitch.
AuditionNoteOffNoteEventHandlerRaised when a key of the side keyboard, clicked to listen, is released.
ViewChangedEventHandlerRaised after the roll redrew because of scrolling, zooming, note edits, snap or skin changes. Companion views (e.g. ControllerLane) use it to stay aligned.
PlayheadMovedEventHandlerRaised when PlayheadPosition changes (cheap; the grid is not redrawn).
NotesEditedRoutedEventHandlerRaised once per completed edit gesture (mouse-up, key press). Hook undo snapshots here.

#Methods

MethodDescription

XToBeat(double x)The position in beats at an x coordinate of the control.
PitchToY(int pitch)The y coordinate of the top of a note's row.
YToPitch(double y)The MIDI note at a y coordinate of the control.
GetGridStep()Visible grid spacing in beats: the snap value, coarsened until lines are at least 6 px apart.
