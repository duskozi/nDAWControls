Controls / Note editing

StepSequencer

A drum-machine grid with velocity per step, row labels, groups and a playhead.

<daw:StepSequencer>
SkinGraphite

#Overview

StepSequencer shows and edits a StepPattern: a grid of rows × steps where each cell holds a velocity (0 = off). CurrentStep shows the playhead, and StepsPerGroup shades groups (usually steps per beat).

Use it for

  • drum machines, arpeggiator and gate patterns, any on/off grid in time

#Quick start

XAML
<daw:StepSequencer x:Name="steps" Height="140" StepsPerGroup="4"/>
C#
var pattern = new StepPattern(rows: 4, steps: 16);
pattern.SetVelocity(0, 0, 120);      // kick on step 1
pattern.SetVelocity(1, 4, 110);      // snare on step 5
steps.Pattern = pattern;
steps.RowLabels = new[] { "Kick", "Snare", "Hat", "Perc" };

#Examples

#Playing the pattern

Read the pattern from your sequencer thread and show the step on the UI thread. See the step sequencer recipe for a complete engine.

C#
void OnStep(int step)                               // sequencer thread
{
    for (int row = 0; row < pattern.Rows; row++)
    {
        int v = pattern.GetVelocity(row, step);
        if (v > 0) midiOut.NoteOn(9, drumNotes[row], v);
    }
    Dispatcher.BeginInvoke(() => steps.CurrentStep = step);
}

#Reacting to edits

C#
pattern.StepChanged += (s, e) => Debug.WriteLine($"row {e.Row} step {e.Step} = {e.Velocity}");

#Properties

PropertyTypeDefaultDescription
PatternStepPatternnullThe steps shown and edited.
RowLabelsIList<string>nullLane names drawn in the label column (e.g. Kick, Snare, Hat).
LabelWidthdouble64Width of the row label column in pixels.
StepsPerGroupint4Steps per shaded group (usually steps per beat).
CurrentStepint-1Playhead step, or -1 when stopped.
DefaultVelocityint100Velocity of steps switched on with the mouse or Space.
CellSpacingdouble3Gap between cells in pixels.
Colour properties (4)

Each one is set by the skin. Set it on one control to override the skin for that control only.

PropertyDescription
StepOffBrushBrush for the steps that are off.
StepOnBrushBrush for the steps that are on.
GroupBrushBrush for the every other group of steps.
PlayheadBrushBrush for the playhead line.
