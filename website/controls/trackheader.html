Controls / Mixer and layout

TrackHeader

The header of a track in an arranger or track list: colour, number, name, mute, solo, output and activity.

<daw:TrackHeader>
SkinGraphite

#Overview

TrackHeader is one row of a track list: a colour bar, number and name, a subtitle, mute and solo buttons, a "show on piano" toggle, an output device selector and an activity LED. Click the header body to select the track.

Use it for

  • the track list of a sequencer or MIDI player, next to piano roll lanes

#Quick start

XAML
<daw:TrackHeader TrackNumber="1" TrackName="Piano" Subtitle="Ch 1 · Grand Piano" TrackColor="#FF6FA8FF"
                 IsMuted="{Binding IsMuted, Mode=TwoWay}" IsSoloed="{Binding IsSoloed, Mode=TwoWay}"
                 OutputDevices="{Binding MidiOutputs}" SelectedOutputDevice="{Binding Output, Mode=TwoWay}"/>
C#
header.NoteOn(note, velocity);          // lights the activity LED
header.NoteOff(note);
header.HeaderClicked += (s, e) => SelectTrack(1);

#Examples

#Showing mute and solo state

IsAudible="False" dims the header. Set it from your solo logic, so tracks silenced by another track's solo look muted too.

C#
bool anySolo = tracks.Any(t => t.IsSoloed);
foreach (var t in tracks) t.Header.IsAudible = !t.IsMuted && (!anySolo || t.IsSoloed);

#Compact header

XAML
<daw:TrackHeader TrackName="Drums" TrackColor="#FFFF6B5A" ShowDeviceSelector="False" ShowActivity="False"/>

#API reference

#Properties

PropertyTypeDefaultDescription
TrackNamestring"Track"Track name.
TrackNumberint1Track number shown before the name.
SubtitlestringnullSecond line, e.g. "Ch 1 · Grand Piano · 532 notes".
TrackColorBrushnullTrack colour, shown as the bar on the left.
IsMutedbool—Whether the track is muted.
IsSoloedbool—Whether the track is soloed.
IsShownOnPianobool—Whether this track's notes are drawn on the keyboard / piano roll.
IsSelectedbool—Whether this is the selected track (drawn highlighted).
IsAudiblebooltrueFalse when muted or silenced by another track's solo; the header dims (set by the app).
OutputDevicesIEnumerablenullOutput devices offered in the selector.
SelectedOutputDeviceobjectnullThe selected output device.
ShowDeviceSelectorbooltrueWhether the output device selector is shown.
ShowActivitybooltrueWhether the MIDI activity LED is shown.

#Events

EventHandlerDescription
HeaderClickedRoutedEventHandlerClicked on the header body (not a button) – select the track.

#Methods

MethodDescription
NoteOn(int note, int velocity)Shows a note-on on the activity LED.
NoteOff(int note)Shows a note-off on the activity LED.
ControlChange(int controller, int value)Shows a control change on the activity LED.
PitchBend(int value)Shows pitch bend on the activity LED.
ProgramChange(int program)Shows a program change on the activity LED.
AllNotesOff()Clears the activity LED's held notes.
