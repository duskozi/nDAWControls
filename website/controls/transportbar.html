Controls / Buttons and transport

TransportBar

A complete transport in one control: buttons, position display, tempo and time signature.

<daw:TransportBar>
SkinGraphite

#Overview

TransportBar has to-start, rewind, forward, stop, play, record, loop and metronome buttons, a position LCD and a tempo field. Its state properties (IsPlaying, IsRecording, IsLooping, IsMetronomeOn, Tempo, Position) bind two-way, and command properties let your view-model react to the buttons.

Use it for

  • the top bar of a sequencer, player or recorder

#Quick start

XAML
<daw:TransportBar Tempo="{Binding Tempo, Mode=TwoWay}" BeatsPerBar="4" BeatUnit="4"
                  IsPlaying="{Binding IsPlaying, Mode=TwoWay}" IsLooping="{Binding IsLooping, Mode=TwoWay}"
                  PlayCommand="{Binding PlayCommand}" StopCommand="{Binding StopCommand}"
                  RecordCommand="{Binding RecordCommand}"/>
C#
// Show the engine position every frame:
CompositionTarget.Rendering += (s, e) => transport.Position = engine.PositionInBeats;

#Examples

#Without commands

Every command is optional. Without a RewindCommand or ForwardCommand the bar moves Position by SeekStep beats (one 4/4 bar by default), and without a ToStartCommand it sets Position to 0. So for a simple player, binding IsPlaying and reading Position is enough.

XAML
<daw:TransportBar x:Name="transport" Tempo="124" IsLooping="True" SeekStep="1"/>
C#
transport.PlayCommand = new RelayCommand<bool>(playing =>
{
    if (playing) engine.Start(transport.Position); else engine.Pause();
});

#Tips

  • PlayCommand and RecordCommand get the new IsPlaying / IsRecording value as their parameter.
  • Position is in beats (quarter notes). The display shows bars, beats and ticks.

#API reference

#Properties

PropertyTypeDefaultDescription
IsPlayingbool—Whether playback is running.
IsRecordingbool—Whether recording is on.
IsLoopingbool—Whether the loop button is on.
IsMetronomeOnbool—Whether the metronome button is on.
Positiondouble0Song position in beats.
Tempodouble120Tempo in beats per minute.
BeatsPerBarint4Beats per bar, for the position display.
BeatUnitint4Denominator of the time signature (display only).
PlayCommandICommand—Executed when Play is clicked; parameter is the new IsPlaying value.
StopCommandICommand—Stop button.
RecordCommandICommand—Record button; the parameter is the new IsRecording.
RewindCommandICommand—Rewind button. Without a command the bar moves Position back by SeekStep.
ForwardCommandICommand—Fast-forward button. Without a command the bar moves Position on by SeekStep.
ToStartCommandICommand—Go-to-start button. Without a command the bar just sets Position to 0.
SeekStepdouble4Beats moved by rewind / forward when no command handles them (default one 4/4 bar).
