ValueBox

A compact numeric field: drag or scroll it like a knob, or double-click and type a value.

<daw:ValueBox>
SkinGraphite

#Overview

ValueBox looks like an LCD field and behaves like a knob: drag up and down, use the wheel or the arrow keys. A double-click (or Enter) opens a text editor for typing an exact value. The typed text may contain units and either decimal separator, so "120 bpm" and "1,5" both work.

Use it for

  • tempo, transpose, number of voices, MIDI channel, sample offsets, anything where the exact number matters

#Quick start

XAML
<daw:ValueBox Label="TEMPO" Minimum="20" Maximum="300" Width="80"
              Value="{Binding Tempo, Mode=TwoWay}"
              ValueFormatter="{x:Static daw:ValueFormatters.Tempo}"/>

#Examples

#Whole numbers with a sign and a unit

XAML
<daw:ValueBox Label="TRANSPOSE" Minimum="-24" Maximum="24" Step="1" Value="0" Width="90"
              ValueStringFormat="{}{0:+0;-0;0}" Unit="st"/>

#Editing from code

BeginEdit, CommitEdit and CancelEdit open and close the text editor; IsEditing tells you whether it is open.

C#
tempoBox.BeginEdit();                    // e.g. from a "Tap tempo" menu item
if (ValueBox.TryParse("128 bpm", out double bpm)) tempoBox.Value = bpm;   // static helper

#Mouse and keyboard

InputWhat it does
Drag up or downChanges the value (Shift for fine)
Mouse wheel / arrow keysSteps
Double-click or EnterOpens the text editor
Enter / Esc in the editorApplies / cancels the typed value
DeleteBack to DefaultValue

#API reference

#Properties

ValueBox also has everything from WPF's RangeBase (Minimum, Maximum, Value, ValueChanged, SmallChange, LargeChange) and the shared value-control properties (DefaultValue, Taper, Step, Label, ValueFormatter, MinimumText …).

PropertyTypeDefaultDescription
IsEditing read-onlyboolfalseTrue while the text editor is shown.
UnitstringnullOptional unit caption drawn after the value (e.g. "BPM").

#Methods

MethodDescription
BeginEdit()Opens the text editor (also on double-click or Enter).
CommitEdit()Closes the text editor and applies the typed value, if it changed and parses.
CancelEdit()Closes the text editor without changing the value.
TryParse(string? text, out double value)Parses user text, tolerating units ("120 bpm") and either decimal separator: "1.5", "1,5", ".5", "-,5". When both separators appear ("1,234.5" or "1.234,5") the last one is the decimal point and the other groups thousands. Text with the same separator twice ("1.2.3") is rejected.
