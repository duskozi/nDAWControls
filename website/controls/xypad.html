Controls / Parameters

XYPad

Two parameters at once on a square pad, such as filter cutoff and resonance.

<daw:XYPad>
SkinGraphite

#Overview

XYPad moves a puck over a grid. XValue and YValue are both normalized from 0 to 1 (Y = 1 at the top), so you map them to real ranges in your view-model. A double-click returns the puck to DefaultX and DefaultY.

Use it for

  • filter cutoff × resonance, reverb size × damping, vector synthesis, pan × distance, performance effects

#Quick start

XAML
<daw:XYPad Width="260" Height="180" XLabel="cutoff" YLabel="resonance"
           XValue="{Binding CutoffNorm, Mode=TwoWay}" YValue="{Binding Resonance, Mode=TwoWay}"/>
C#
// In the view-model: map 0..1 to 20 Hz..20 kHz on a log scale.
public double CutoffNorm
{
    get => Math.Log(Cutoff / 20) / Math.Log(1000);
    set { Cutoff = 20 * Math.Pow(1000, value); OnPropertyChanged(); }
}

#Examples

#Grid, puck and default position

XAML
<daw:XYPad Width="200" Height="200" GridDivisions="8" PuckSize="18" DefaultX="0.5" DefaultY="0.25"/>

#One undo step per drag

C#
pad.DragStarted   += (s, e) => undo.BeginGroup("Filter");
pad.DragCompleted += (s, e) => undo.EndGroup();

InputWhat it does
Click or dragMoves the puck
Shift + dragFine movement
Double-clickBack to the default position
Arrow keysNudge the puck
