FAQ

Short answers to the questions that come up most.

#Which .NET versions are supported?

The package has builds for .NET 8 (net8.0-windows) and .NET 10 (net10.0-windows). .NET Framework is not supported.

#Does it work on ARM64 or in 32-bit apps?

Yes. The native renderer is x64 only, so ARM64 and x86 processes draw the same frames as vectors. They look the same and are only slightly slower.

#The controls look fine, but is the native renderer used?

Build for x64 and make sure the Microsoft Visual C++ Redistributable (x64) is installed. If the native renderer can't load, the controls fall back to vector drawing and write one line to the debug output that says so.

#Do I need to copy NinePatchLib.dll myself?

No. It comes with the NinePatch.Core package (a dependency of nDAWControls) and lands next to your exe, or under runtimes/win-x64/native, automatically.

#Can I use the controls without a skin?

The default theme is Graphite, so the controls look right without calling SkinManager at all. Call SkinManager.Apply only to pick another skin.

#How do I make my own windows match the skin?

Use the skin colours with DynamicResource, for example Background="{DynamicResource {x:Static daw:DawSkinKeys.WindowBackground}}". See Skins.

#Can I call PushLevels or NoteOn from my audio thread?

Yes, those are lock-free and made for it. Everything else belongs to the UI thread. See Threading.

#Why does my PianoKeyboard or PianoRoll look small or empty?

Give it a size. The keyboard asks for 16 pixels per white key and a height of 90 by default; the piano roll needs a sized cell (a star row or column) and a ScrollViewer with CanContentScroll="True".

#Is there a designer preview in Visual Studio?

The controls are normal WPF controls with default styles, so they show in the XAML designer like other controls. The fastest way to explore them is still the gallery app.

#Can I change the look beyond colours?

Yes. The controls are lookless, so you can restyle or re-template them like any WPF control. Most apps only need skin keys and brush properties.

#What license is it?

MIT. Use it in free and commercial apps. The source is on GitHub.

#Where do I report a bug or ask for a feature?

Open an issue on GitHub. A screenshot and the XAML you used help a lot.
